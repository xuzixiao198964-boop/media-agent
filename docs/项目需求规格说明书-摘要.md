## 🛠️ 裸机部署关键步骤

### 1. 环境准备 (完整命令)
```bash
# 系统更新和基础软件
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3.9 postgresql redis-server nginx nodejs

# 创建应用用户
sudo useradd -r -s /bin/false media-agent
sudo mkdir -p /opt/media-agent
sudo chown -R media-agent:media-agent /opt/media-agent
```

### 2. 应用部署
```bash
# 克隆代码和安装依赖
cd /opt/media-agent
sudo -u media-agent git clone <repository-url> .
sudo -u media-agent python3.9 -m venv venv
sudo -u media-agent /opt/media-agent/venv/bin/pip install -r backend/requirements.txt

# 前端构建
cd frontend
sudo -u media-agent npm install
sudo -u media-agent npm run build
cd ..

# 数据库迁移
sudo -u media-agent /opt/media-agent/venv/bin/alembic upgrade head
```

### 3. 服务配置
```bash
# systemd服务配置
sudo cp deployment/systemd/*.service /etc/systemd/system/
sudo systemctl daemon-reload

# Nginx配置
sudo cp deployment/nginx/media-agent.conf /etc/nginx/sites-available/
sudo ln -s /etc/nginx/sites-available/media-agent.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# SSL证书
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d media-agent.example.com
```

### 4. 启动服务
```bash
sudo systemctl enable media-agent-backend
sudo systemctl enable media-agent-frontend
sudo systemctl enable media-agent-celery
sudo systemctl enable media-agent-celery-beat

sudo systemctl start media-agent-backend
sudo systemctl start media-agent-frontend
sudo systemctl start media-agent-celery
sudo systemctl start media-agent-celery-beat
```

### 5. 安全加固
```bash
# 防火墙
sudo ufw allow ssh
sudo ufw allow http
sudo ufw allow https
sudo ufw enable

# SSH安全
sudo sed -i 's/#PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
sudo sed -i 's/#PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart sshd

# 文件权限
sudo chmod 750 /opt/media-agent
sudo chmod 640 /opt/media-agent/.env
sudo chmod 750 /opt/media-agent/data
```
