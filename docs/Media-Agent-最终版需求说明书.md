## 1. 具体功能需求

### 1.1 用户认证管理功能

#### 用户注册
- **必填字段**: 2个
  1. 用户名: 3-64字符，只允许字母(a-z,A-Z)、数字(0-9)、下划线(_)
  2. 密码: 12-128字符，必须包含4种字符类型（大写字母、小写字母、数字、特殊字符）
- **并发控制**:
  - 同一IP地址: 1分钟内最多注册3个账号
  - 用户名唯一性: 不允许重复（大小写敏感）
  - 注册频率: 单个用户24小时内最多注册1次

#### 用户登录
- **登录方式**: 仅用户名+密码登录
- **登录限制规则**:
  - IP级别限制（5分钟时间窗口）:
    - 失败1-2次: 正常响应
    - 失败3-4次: 增加1秒响应延迟
    - 失败5次: 该IP封锁30分钟
  - 用户级别限制（10分钟时间窗口）:
    - 失败1次: 正常响应
    - 失败2次: 增加2秒响应延迟
    - 失败3次: 该用户账号锁定15分钟
- **会话管理**:
  - JWT访问令牌: 30分钟有效期
  - JWT刷新令牌: 7天有效期
  - 自动刷新: 访问令牌过期前5分钟自动刷新
  - 并发会话控制: 每个用户最多3个活跃会话
  - 新登录策略: 第4个登录时，自动踢出最早的会话

#### 密码管理
- **密码修改规则**:
  - 必须验证旧密码
  - 新密码必须符合注册时的密码规则
  - 不能使用最近5次使用过的密码
  - 24小时内最多修改3次密码
- **密码过期策略**:
  - 密码有效期: 90天
  - 过期提醒: 过期前7天开始提醒
  - 强制修改: 密码过期后必须修改才能登录

#### 用户信息管理
- **可修改信息**:
  1. 显示名称: 1-50字符，支持任意Unicode字符
  2. 头像: 支持JPG/PNG格式，最大2MB，自动裁剪为100x100像素
  3. 个人简介: 0-200字符，纯文本
- **登录记录**:
  - 显示最近20条登录记录
  - 每条记录包含: 登录时间、IP地址、设备类型、登录结果
  - 异常登录标记: 新设备、新地区登录自动标记
- **活跃会话管理**:
  - 显示当前所有活跃会话
  - 每条会话包含: 登录时间、最后活动时间、IP地址、设备信息
  - 远程登出: 用户可以强制终止任意活跃会话

### 1.2 资讯抓取功能

#### RSS源管理
- **支持的RSS格式**: 2种
  1. RSS 2.0格式
  2. Atom 1.0格式
- **源添加验证**:
  - URL格式验证: 必须为http或https开头的URL
  - 可达性验证: 5秒内必须响应
  - 格式验证: 必须包含<title>和<item>/<entry>元素
  - 内容验证: 至少包含1篇文章内容
- **抓取频率配置**: 7种预设频率
  1. 15分钟
  2. 30分钟
  3. 1小时
  4. 2小时
  5. 6小时
  6. 12小时
  7. 24小时
- **分类系统**: 3级分类
  1. 一级分类（固定）: 新闻、科技、娱乐、体育、财经、生活
  2. 二级分类（用户自定义）: 最多10个
  3. 标签（用户自定义）: 每个RSS源最多5个标签

#### 网页抓取
- **智能解析算法**: 使用Readability算法变体
- **目标准确率**:
  - 内容提取准确率: >90%
  - 广告去除率: >95%
  - 正文识别准确率: >92%
- **图片处理规则**:
  - 支持的图片格式: JPG, PNG, GIF, WebP
  - 自动下载: 最多下载前5张图片
  - 图片优化: 统一转换为WebP格式，最大宽度800像素
  - 存储策略: 本地存储，7天缓存
- **去重机制**:
  - 哈希算法: SHA-256
  - 比较内容: 标题+正文前500字符
  - 相似度阈值: 95%以上视为重复内容
  - 去重范围: 同一用户7天内的内容

#### 内容管理
- **文章列表显示**:
  - 分页大小: 每页20条（固定）
  - 排序方式: 4种
    1. 抓取时间（最新优先）
    2. 发布时间（最新优先）
    3. 相关性（搜索时使用）
    4. 评分（高质量优先）
  - 显示字段: 标题、来源、抓取时间、分类、评分
- **内容预览功能**:
  - 预览长度: 正文前500字符
  - 图片显示: 显示第一张图片的缩略图（100x100像素）
  - 元数据显示: 标题、作者、发布时间、字数统计
- **批量操作支持**:
  - 选择方式: 全选、反选、手动选择
  - 支持操作: 5种
    1. 删除
    2. 标记已读
    3. 导出为TXT文件
    4. 添加到收藏
    5. 批量分类
- **搜索过滤功能**:
  - 搜索字段: 3个
    1. 标题
    2. 正文内容
    3. 来源
  - 过滤条件: 5个
    1. 时间范围（按抓取时间）
    2. 分类
    3. 标签
    4. 评分范围
    5. 阅读状态

#### 质量控制
- **内容评分算法**:
  - 评分维度: 4个
    1. 长度分: 500-2000字得满分，其他按比例计算
    2. 完整性分: 包含标题、正文、至少1张图片
    3. 可读性分: 基于Flesch Reading Ease分数
    4. 时效性分: 发布时间与抓取时间差
  - 总分计算: 加权平均，权重分配: 长度30%，完整性30%，可读性20%，时效性20%
  - 评分等级: 0-100分，<60差，60-80中，>80优
- **人工审核流程**:
  - 审核触发条件: 2种
    1. 评分<60自动进入审核队列
    2. 用户手动标记需要审核
  - 审核状态: 3种
    1. 待审核
    2. 审核通过
    3. 审核拒绝
  - 审核操作: 通过、拒绝、修改分类
- **黑名单管理**:
  - 自动加入条件: 3种
    1. 连续10次抓取失败
    2. 连续20篇文章评分<40
    3. 检测到恶意内容
  - 黑名单期限: 30天后自动解除
  - 手动管理: 添加、移除、查看详情

### 1.3 视频处理功能

#### 视频上传
- **支持的视频格式**: 8种
  1. MP4 (.mp4)
  2. MOV (.mov)
  3. AVI (.avi)
  4. MKV (.mkv)
  5. FLV (.flv)
  6. WMV (.wmv)
  7. WebM (.webm)
  8. MPEG (.mpeg, .mpg)
- **文件大小限制**:
  - 单个文件: 最大2GB
  - 用户总存储: 免费用户2GB，付费用户10GB（可扩展）
- **分片上传规则**:
  - 分片大小: 5MB
  - 最大分片数: 400个（对应2GB文件）
  - 断点续传: 支持，记录已上传分片
  - 并发上传: 最多3个分片同时上传
- **进度显示信息**:
  - 上传进度: 百分比（0-100%）
  - 上传速度: MB/秒
  - 已上传大小: MB
  - 剩余时间: 分钟:秒格式
  - 当前状态: 准备、上传中、完成、失败

#### 视频预览
- **在线预览技术**:
  - 视频转码: 上传后自动转码为H.264/AAC编码的MP4格式
  - 分辨率: 自动生成360p、720p、1080p（如果源文件支持）
  - 流媒体协议: HLS（HTTP Live Streaming）
  - 播放器: HTML5 video.js
- **缩略图生成规则**:
  - 生成时间点: 3个
    1. 视频开头（0秒）
    2. 视频1/3处
    3. 视频2/3处
  - 缩略图尺寸: 320x180像素
  - 格式: JPG，质量80%
  - 数量: 最多3张，用户可选择默认显示哪张
- **视频信息显示**:
  - 基本信息: 8项
    1. 文件名
    2. 文件大小（MB）
    3. 时长（时:分:秒格式）
    4. 分辨率（宽x高）
    5. 视频编码
    6. 音频编码
    7. 帧率（fps）
    8. 码率（Mbps）
  - 元数据: 标题、描述、标签、分类
- **时间轴预览功能**:
  - 预览精度: 1秒
  - 拖动响应: <100毫秒
  - 预览图: 生成时间轴缩略图（每10秒1张）
  - 关键帧标记: 自动检测场景变化点

#### 视频管理
- **视频列表显示**:
  - 视图模式: 2种
    1. 网格视图: 显示缩略图、标题、时长
    2. 列表视图: 显示文件名、大小、上传时间、状态
  - 每页数量: 网格视图20个，列表视图50个
  - 排序方式: 4种
    1. 上传时间（最新）
    2. 文件名（A-Z）
    3. 文件大小（大-小）
    4. 时长（长-短）
- **分类标签系统**:
  - 分类层级: 2级
    1. 一级分类（固定）: 影视、音乐、教育、娱乐、其他
    2. 二级分类（用户自定义）: 最多10个
  - 标签系统: 用户自定义，每个视频最多10个标签
  - 智能标签: 基于内容分析自动建议标签
- **搜索功能**:
  - 搜索字段: 5个
    1. 文件名
    2. 标题
    3. 描述
    4. 标签
    5. 分类
  - 过滤条件: 6个
    1. 上传时间范围
    2. 文件大小范围
    3. 视频时长范围
    4. 分辨率
    5. 视频状态（原始、处理中、已完成）
    6. 隐私设置（公开、私有）
- **批量操作支持**:
  - 支持的操作: 6种
    1. 批量删除
    2. 批量移动（到其他分类）
    3. 批量添加标签
    4. 批量修改隐私设置
    5. 批量下载（打包为ZIP文件）
    6. 批量转码
  - 批量限制: 一次最多操作100个文件

#### 视频处理
- **格式转换规则**:
  - 目标格式: MP4（H.264视频编码/AAC音频编码）
  - 支持的源格式: 同上传支持格式
  - 转码预设: 3种
    1. 高质量: CRF 18，音频128kbps
    2. 平衡: CRF 23，音频96kbps
    3. 快速: CRF 28，音频64kbps
  - 转码速度: 根据服务器硬件性能，目标实现实时转码（1倍速）
- **分辨率调整规则**:
  - 支持的输出分辨率: 6种
    1. 240p (426x240)
    2. 360p (640x360)
    3. 480p (854x480)
    4. 720p (1280x720)
    5. 1080p (1920x1080)
    6. 原始分辨率
  - 缩放算法: Lanczos
  - 宽高比: 保持原始宽高比，自动添加黑边
- **水印添加规则**:
  - 水印类型: 2种
    1. 文字水印: 支持自定义文字、字体、大小、颜色、透明度
    2. 图片水印: 支持PNG格式（带透明度），最大200x100像素
  - 水印位置: 9个预设位置（左上、中上、右上、左中、中心、右中、左下、中下、右下）
  - 水印大小: 最大为视频宽度的20%
  - 水印透明度: 10%-90%可调
- **元数据编辑功能**:
  - 可编辑字段: 6个
    1. 标题: 1-100字符
    2. 描述: 0-500字符
    3. 作者: 0-50字符
    4. 版权信息: 0-100字符
    5. 分类: 选择现有分类
    6. 标签: 添加/删除标签
  - 元数据标准: 遵循MP4标准元数据字段

### 1.4 AI内容生成功能

#### AI文案生成（基于原有项目实际能力）
- **实际支持的AI模型**: DeepSeek Chat模型
  - 模型端点: `https://api.deepseek.com/chat/completions`
  - 模型名称: `deepseek-chat`
  - 调用方式: 通过HTTP POST请求调用DeepSeek API
- **实际文案生成能力**:
  1. **新闻口播文案生成**:
     - 输入: 新闻标题、摘要、正文节选
     - 输出: 80-160字中文口播文案
     - 特点: 语气自然、有节奏感，适合短视频口播
     - 提示词: "你是短视频口播撰稿人。根据新闻写一段中文口播，80~160字，语气自然、有节奏感，不要标题前缀，不要 Markdown。"
  
  2. **用户需求文案生成**:
     - 输入: 用户视频制作需求描述
     - 输出: 80-200字中文口播稿
     - 特点: 根据用户需求定制文案，适合竖屏短视频
     - 提示词: "你是短视频口播撰稿人。根据用户的制作需求写一段中文口播稿，80~200字，语气自然、有节奏感，适合竖屏短视频；不要标题前缀，不要 Markdown。"
- **API参数配置**:
  - 温度 (temperature): 0.7（创意与稳定性的平衡）
  - 最大令牌数 (max_tokens): 400-500
  - 超时时间: 60秒
  - 错误处理: API调用失败时返回备选文案
- **实际限制**:
  - 文案长度: 最大800字符（安全截断）
  - 输入长度: 摘要/正文节选最大1200字符
  - 无API密钥时: 返回简化文案
  - 错误处理: 异常时返回备选方案

#### TTS语音合成（基于原有项目实际能力）
- **实际支持的TTS服务**: 三级备选方案
  1. **第一优先级: 腾讯云TTS**（需配置API密钥）
     - 服务地址: `tts.tencentcloudapi.com`
     - 支持功能: 标准语音合成、VRS音色克隆
     - 语音类型: 可配置`tencent_tts_voice_type`（默认101001）
     - 区域配置: `tencent_tts_region`（默认ap-guangzhou）
     - 音色克隆: 支持VRS一句话克隆生成的FastVoiceType
  
  2. **第二优先级: Edge TTS**（本地备选，无需API密钥）
     - 语音库映射:
       - zh-CN: `zh-CN-XiaoxiaoNeural`（中文，女声）
       - en-US: `en-US-EmmaNeural`（英文，女声）
       - ja-JP: `ja-JP-NanamiNeural`（日文，女声）
     - 特点: 无需API密钥，质量中等
  
  3. **第三优先级: OpenAI TTS**（需配置API密钥）
     - 模型: `gpt-4o-mini-tts`（可配置）
     - 语音: `alloy`（可配置）
     - 调用端点: `https://api.openai.com/v1/audio/speech`

- **实际调用流程**:
  1. 优先使用腾讯云TTS（如果配置了API密钥且支持音色克隆）
  2. 其次使用Edge TTS（作为本地备选方案）
  3. 最后尝试OpenAI TTS（如果配置了API密钥）
  4. 全部失败时抛出运行时错误

- **实际功能限制**:
  - 语音选择: 基于语言代码自动选择，不支持细粒度语音选择
  - 情感控制: 不支持情感参数调节
  - 语速调整: 不支持语速调整
  - 音频格式: 输出为MP3格式，参数固定
  - 错误处理: 三级备选方案，全部失败时报错

- **配置要求**:
  - 腾讯云TTS: 需要`tencent_tts_secret_id`和`tencent_tts_secret_key`
  - OpenAI TTS: 需要`openai_api_key`
  - Edge TTS: 无需配置，但需要安装`edge-tts`包

#### 视频处理功能（基于原有项目实际能力）
- **实际支持的视频处理能力**:
  1. **阿里云百炼VideoRetalk（视频口型替换）**:
     - 服务地址: `https://dashscope.aliyuncs.com/api/v1/services/aigc/image2video/video-synthesis/`
     - 功能: 将输入视频的口型与输入音频同步（口型替换）
     - 输入要求: 视频文件 + 音频文件（需公网可访问URL）
     - 输出: 口型同步后的视频文件
     - 分辨率: 可配置`videoretalk_resolution`（默认480P）
  
  2. **FFmpeg本地视频处理**:
     - 功能: 视频转码、音频提取、时长探测、格式转换
     - 支持格式: 通过FFmpeg支持多种视频格式
     - 本地处理: 无需云服务，直接在服务器处理

  3. **视频渲染合成**:
     - 功能: 将文案、音频、图片等素材合成为视频
     - 工具: 基于FFmpeg的视频合成
     - 输出: 完整的短视频文件

- **实际工作流程**:
  1. **素材准备阶段**:
     - 获取输入视频文件（用户上传或生成）
     - 生成TTS音频文件
     - 准备其他素材（图片、背景音乐等）
  
  2. **视频处理阶段**:
     - 使用VideoRetalk进行口型同步（如需要）
     - 使用FFmpeg进行视频转码和格式处理
     - 合成最终视频文件
  
  3. **输出交付阶段**:
     - 生成视频预览
     - 保存到输出目录
     - 提供下载和发布接口

- **实际限制**:
  - VideoRetalk需要公网可访问的输入文件URL
  - 需要配置`dashscope_api_key`
  - 异步任务处理，需要轮询任务状态
  - 分辨率选项有限（如480P、720P等）
  - 不支持复杂的视频模板系统
  - 字幕添加、转场效果等高级功能需额外实现

- **配置要求**:
  - 阿里云百炼: 需要`dashscope_api_key`
  - 公网访问: 需要配置`public_base_url`（如`http://104.244.90.202:8080`）
  - FFmpeg: 需要在服务器安装FFmpeg工具
    6. 社交媒体模板: 竖屏格式+大字标题+背景音乐
    7. 广告宣传模板: 快速剪辑+音效+文字强调
    8. 个人vlog模板: 自拍视频+字幕+转场效果
  - 模板参数: 每个模板可配置
    1. 视频尺寸: 横屏(16:9)、竖屏(9:16)、方形(1:1)
    2. 背景颜色/图片/视频
    3. 字体样式、大小、颜色
    4. 转场效果类型和时长
    5. 背景音乐选择和音量
- **素材组合规则**:
  - 支持素材类型: 4种
    1. 文案: 文本内容
    2. 语音: 音频文件或TTS生成
    3. 图片: JPG/PNG，支持多张
    4. 视频: MP4，支持片段
  - 时间轴对齐: 自动根据语音时长调整其他素材
  - 素材匹配: 根据文案内容自动推荐相关图片/视频
- **字幕生成实现**:
  - 生成方式: 2种
    1. 语音识别: 从音频生成字幕
    2. 文案同步: 根据文案和语音时间生成
  - 字幕样式: 可配置字体、大小、颜色、背景、位置
  - 同步精度: 字级别同步，误差<100ms
  - 字幕文件: 同时生成SRT和ASS格式
- **转场效果库**:
  - 基础转场: 6种
    1. 淡入淡出
    2. 滑动
    3. 缩放
    4. 旋转
    5. 擦除
    6. 溶解
  - 高级转场: 4种
    1. 立方体旋转
    2. 页面翻转
    3. 万花筒
    4. 粒子效果
  - 转场时长: 0.5秒-3秒可调，默认1秒

#### 流水线管理功能
- **工作流定义元素**:
  - 节点类型: 5种
    1. 输入节点: 接收外部输入
    2. 处理节点: 执行具体处理（如AI生成、TTS合成）
    3. 判断节点: 条件判断，决定流程分支
    4. 合并节点: 合并多个分支
    5. 输出节点: 输出最终结果
  - 连接规则: 每个节点最多5个输入，5个输出
  - 参数配置: 每个节点可配置具体参数
- **预定义工作流**: 3种
  1. 资讯转视频工作流:
     输入: RSS源 → 抓取文章 → AI摘要 → TTS语音 → 视频合成 → 发布
  2. 批量处理工作流:
     输入: 文件列表 → 并行处理 → 结果合并 → 批量导出
  3. 审核发布工作流:
     输入: 生成内容 → 人工审核 → 修改调整 → 最终发布
- **批量处理规则**:
  - 并发数量: 根据任务类型限制
    1. AI文案生成: 最多5个并发
    2. TTS语音合成: 最多3个并发
    3. 视频合成: 最多2个并发
  - 优先级设置: 高、中、低3个优先级
  - 失败处理: 自动重试3次，失败后记录日志
- **进度监控显示**:
  - 进度信息: 6项
    1. 当前步骤
    2. 步骤进度（百分比）
    3. 已用时间
    4. 预计剩余时间
    5. 当前状态（运行中、暂停、完成、失败）
    6. 详细日志
  - 更新频率: 每5秒更新一次
  - 历史记录: 保存最近100个工作流执行记录

### 1.5 发布管理功能（基于原有项目实际能力）

#### 实际发布能力
- **当前发布模式**: 模拟发布（Mock Mode）
  - 配置参数: `publish_mode: "mock"`
  - 功能描述: 模拟发布流程，不实际调用平台API
  - 使用场景: 开发测试、功能演示、流程验证

- **发布工作流程**:
  1. **创建发布任务**:
     - 输入: 生成任务ID + 目标平台
     - 输出: 发布任务记录（状态: queued）
     - API端点: `POST /publish/jobs`
  
  2. **异步执行发布**:
     - 触发: Celery异步任务 `run_publish_job_task`
     - 处理: 调用 `run_publish` 函数
     - 状态更新: publishing → success/failed
  
  3. **发布结果记录**:
     - 成功: 状态标记为success，记录mock元数据
     - 失败: 状态标记为failed，记录错误信息
     - 元数据: 包含平台、模拟发布时间、模拟外部ID

- **数据库支持**:
  - 表名: `publish_jobs`
  - 字段:
    - `generation_job_id`: 关联的生成任务ID
    - `platform`: 目标平台名称
    - `status`: 任务状态（queued, publishing, success, failed）
    - `error`: 错误信息（如失败）
    - `meta`: JSON格式的元数据
    - `created_at` / `updated_at`: 时间戳

- **实际限制**:
  - 仅支持模拟发布，不实际调用任何平台API
  - 平台名称仅为标识符，无实际验证
  - 无账号管理功能
  - 无平台特定配置
  - 无实际的内容上传和发布

- **扩展说明**:
  - 代码位置: `backend/app/services/publisher.py`
  - 扩展方法: 修改 `run_publish` 函数，添加实际平台API调用
  - 配置切换: 修改 `publish_mode` 配置项
  - 错误提示: "发布模式 {mode} 尚未实现，请使用 mock 或扩展 publisher.run_publish"
    - 抖音: 话题挑战、位置、@好友
    - 微信视频号: 封面图、位置、可见范围
- **平台监控指标**:
  - 连接状态: 在线、离线、限流、错误
  - API配额: 剩余请求次数、重置时间
  - 发布统计: 今日发布数、成功率、平均耗时
  - 错误日志: 最近错误记录，包含错误码和描述

#### 发布配置功能
- **内容适配规则**:
  - 自动裁剪: 根据平台要求自动裁剪视频尺寸
  - 格式转换: 自动转换为平台支持的格式
  - 时长调整: 超长视频自动分段或加速
  - 元数据适配: 标题、描述、标签根据平台要求调整
- **发布计划选项**:
  - 立即发布: 配置完成后立即发布
  - 定时发布: 指定具体日期和时间
  - 循环发布: 按周期重复发布（每天、每周、每月）
  - 条件发布: 满足条件时发布（如审核通过后）
- **发布策略配置**:
  - 发布频率: 每小时最多5个，每天最多50个
  - 时间窗口: 可设置允许发布的时间段（如9:00-21:00）
  - 重试策略: 失败后重试次数（1-3次）、重试间隔（5-30分钟）
  - 平台选择: 可配置发布到哪些平台，按顺序或并行
- **审核流程步骤**:
  - 审核触发: 2种方式
    1. 所有内容强制审核
    2. 高风险内容自动进入审核（基于内容分析）
  - 审核人员: 可指定具体审核人员或角色
  - 审核标准: 可配置审核 checklist
  - 审核结果: 通过、拒绝、需修改
  - 修改流程: 审核不通过时可修改后重新提交

#### 发布执行功能
- **任务队列管理**:
  - 队列类型: 3种
    1. 高优先级队列: 立即发布任务
    2. 普通队列: 定时发布任务
    3. 低优先级队列: 批量发布任务
  - 队列容量: 每个队列最多1000个任务
  - 任务调度: 基于优先级和时间的智能调度
- **状态跟踪信息**:
  - 任务状态: 6种
    1. 等待中
    2. 准备中
    3. 发布中
    4. 已完成
    5. 失败
    6. 已取消
  - 进度信息: 当前步骤、进度百分比、预计完成时间
  - 详细日志: 每个步骤的详细执行日志
  - 平台响应: 平台返回的原始响应数据
- **失败重试规则**:
  - 重试条件: 3种
    1. 网络错误
    2. 平台API限流
    3. 临时性错误（如平台维护）
  - 重试次数: 最多3次
  - 重试间隔: 指数退避（5分钟、15分钟、45分钟）
  - 永久失败: 重试3次后标记为永久失败
- **结果收集内容**:
  - 成功结果: 平台返回的视频ID、URL、发布时间
  - 失败结果: 错误码、错误信息、失败时间
  - 性能数据: 发布耗时、文件大小、网络速度
  - 平台数据: 平台返回的统计数据（如初始观看量）

#### 发布监控功能
- **实时监控显示**:
  - 当前任务: 运行中任务数量、状态分布
  - 队列状态: 各队列任务数量、等待时间
  - 平台状态: 各平台连接状态、API配额
  - 系统状态: CPU、内存、磁盘使用率
- **统计报表内容**:
  - 发布统计: 今日/本周/本月发布数量、成功率
  - 平台分布: 各平台发布数量占比
  - 时间分布: 各时间段发布数量
  - 成功率分析: 各平台成功率对比
  - 耗时分析: 平均发布耗时、最长/最短耗时
- **异常告警规则**:
  - 告警条件: 5种
    1. 连续5次发布失败
    2. 平台API配额使用超过90%
    3. 系统资源使用超过80%
    4. 队列积压超过100个任务
    5. 网络连接异常超过10分钟
  - 告警级别: 3级（警告、严重、紧急）
  - 告警方式: 系统内通知
- **效果分析指标**:
  - 观看数据: 观看量、完播率、平均观看时长
  - 互动数据: 点赞数、评论数、分享数
  - 增长数据: 粉丝增长、播放量增长
  - 对比分析: 不同内容类型效果对比、不同时间段效果对比

## 2. 性能需求

### 2.1 性能要求原则
- **根据服务器具体性能确定**: 所有性能指标应根据实际部署的服务器硬件配置动态调整
- **可配置性**: 所有性能参数应在配置文件中可调整
- **弹性伸缩**: 系统应支持根据负载自动调整资源分配

### 2.2 任务队列性能要求

#### 任务队列总等待时间要求
- **单个任务总等待时间**:
  - 高优先级任务: 从提交到开始执行，等待时间不超过服务器处理能力的10%
  - 普通优先级任务: 等待时间不超过服务器处理能力的30%
  - 低优先级任务: 等待时间不超过服务器处理能力的50%
- **批量任务总处理时间**:
  - 小批量任务（<10个）: 总处理时间不超过单个任务处理时间的3倍
  - 中批量任务（10-50个）: 总处理时间不超过单个任务处理时间的5倍
  - 大批量任务（>50个）: 总处理时间应可预测，并提供进度预估
- **队列积压处理**:
  - 轻度积压（<50个任务）: 系统自动加速处理
  - 中度积压（50-200个任务）: 系统告警，建议增加资源
  - 重度积压（>200个任务）: 系统自动限流，拒绝新任务提交

#### 任务调度性能
- **调度延迟**: 任务就绪到开始执行的延迟不超过5秒
- **资源分配**: 根据任务类型和优先级智能分配系统资源
- **负载均衡**: 在多实例部署时，任务应均匀分配到各实例

### 2.3 系统响应性能

#### 用户界面响应
- **页面加载时间**: 应根据服务器性能和网络状况动态调整，但应保证用户体验
- **操作响应时间**: 用户操作的响应时间应感知流畅，无明显卡顿

#### API接口响应
- **认证接口**: 响应时间应优先保证，确保用户登录体验
- **数据查询接口**: 响应时间应根据数据量和查询复杂度合理调整
- **文件上传接口**: 应立即响应，后台异步处理

#### 后台任务处理
- **资讯抓取任务**: 处理时间应根据源站响应速度和内容大小调整
- **视频处理任务**: 处理时间应根据视频长度和复杂度调整
- **AI生成任务**: 处理时间应根据模型响应速度和内容长度调整
- **发布任务**: 处理时间应根据平台API响应速度调整

### 2.4 并发处理性能

#### 用户并发
- **并发用户数**: 应根据服务器硬件配置确定最大支持并发数
- **会话管理**: 应支持合理的并发会话数，避免资源耗尽

#### 任务并发
- **资讯抓取并发**: 应根据网络带宽和源站限制调整
- **视频处理并发**: 应根据CPU和内存资源调整
- **AI生成并发**: 应根据AI模型服务能力调整
- **发布任务并发**: 应根据平台API限制调整

### 2.5 资源使用性能

#### 内存使用
- **应用内存**: 各服务内存使用应在合理范围内，避免内存泄漏
- **缓存内存**: 缓存大小应根据可用内存动态调整
- **处理内存**: 大文件处理时应合理控制内存使用

#### CPU使用
- **正常负载**: CPU使用率应在合理范围内，避免持续高负载
- **峰值负载**: 应能处理短期峰值负载，但不应持续
- **任务处理**: CPU密集型任务应合理调度，避免影响系统响应

#### 磁盘I/O
- **读取性能**: 应保证数据读取的响应速度
- **写入性能**: 应保证数据写入的可靠性
- **存储空间**: 应监控存储空间使用，及时清理过期数据

#### 网络I/O
- **内部通信**: 服务间通信应高效可靠
- **外部通信**: 与外部服务的通信应稳定，有重试机制
- **文件传输**: 大文件传输应支持断点续传和进度显示

#### 数据一致性

- **最终一致性**: 非关键数据可保证最终一致性

- **故障转移**: 应有故障自动转移机制

#### 容量规划
- **数据容量**: 应有数据容量监控和预警
- **处理容量**: 应有处理能力监控和扩容机制
- **网络容量**: 应有网络带宽监控和优化

#### 性能降级
- **功能降级**: 高负载时应支持非核心功能降级
- **性能降级**: 应保证核心功能的性能底线
- **体验降级**: 用户体验降级应在可接受范围内

### 3.3 可用性健壮性

#### 服务冗余
- **多实例部署**: 关键服务应多实例部署
- **跨可用区**: 重要服务应跨可用区部署
- **自动故障转移**: 应有自动故障检测和转移机制

#### 数据冗余
- **数据备份**: 重要数据应有定期备份
- **数据复制**: 关键数据应有实时复制
- **异地容灾**: 应有异地容灾方案

#### 网络冗余
- **多线路接入**: 应有多个网络接入线路

### 3.4 安全健壮性

#### 认证安全

- **会话安全**: 会话应有安全机制保护
- **登录安全**: 应有登录失败限制机制

#### 授权安全

- **数据权限**: 应有细粒度的数据访问控制
- **操作审计**: 应有敏感操作审计日志

#### 数据安全
- **传输安全**: 数据传输应加密
- **存储安全**: 敏感数据应加密存储
- **销毁安全**: 数据销毁应彻底

#### 应用安全
- **输入安全**: 应有输入验证和过滤
- **输出安全**: 应有输出编码和过滤
- **代码安全**: 应有代码安全审查机制

## 4. 具体业务路径

### 4.1 资讯转视频业务路径

#### 路径1: 自动资讯转视频
1. 用户添加RSS源，配置抓取频率
2. 系统定时抓取RSS源内容
3. 系统解析文章内容，提取正文
4. 使用DeepSeek模型生成文章摘要
5. 使用TTS合成语音
6. 使用视频模板合成视频
7. 自动发布到配置的平台
8. 记录发布结果，发送通知

#### 路径2: 手动资讯转视频
1. 用户浏览抓取的文章列表
2. 用户选择感兴趣的文章
3. 用户配置生成参数（模板、风格、长度等）
4. 系统生成文案、语音、视频
5. 用户预览生成结果
6. 用户确认并保存或发布
7. 系统记录生成历史

#### 路径3: 批量资讯转视频
1. 用户选择多篇文章
2. 用户配置批量处理参数
3. 系统创建批量处理任务
4. 系统后台批量处理
5. 用户查看处理进度
6. 处理完成后，用户批量下载或发布
7. 系统生成批量处理报告

### 4.2 视频处理业务路径

#### 路径1: 单视频上传处理
1. 用户选择本地视频文件
2. 系统分片上传文件
3. 上传完成后自动转码
4. 生成视频预览信息
5. 用户编辑视频信息（标题、描述、标签等）
6. 用户选择处理操作（格式转换、分辨率调整等）
7. 系统处理视频
8. 处理完成后保存到视频库

#### 路径2: 批量视频处理
1. 用户选择多个视频文件

## 6. 服务器性能与发布策略分析

### 6.1 服务器性能分析

#### 硬件配置
- **操作系统**: Windows 10 专业版 64位
- **CPU**: Intel Core i7-7700 @ 3.60GHz (4核8线程)
- **内存**: 32GB（可用16.7GB）
- **存储**: 需要检查磁盘空间

#### 性能评估
- **CPU性能**: 中等性能，适合AI推理和视频处理
- **内存容量**: 充足，可支持多个服务并发运行
- **部署环境**: Windows环境，需要适配非Linux部署方案
- **本地化能力**: 性能足够支持本地化部署，减少云服务依赖

### 6.2 现有技术栈分析

#### AI服务
1. **DeepSeek API**: 主要AI模型，用于文案生成和内容摘要
2. **腾讯云TTS**: 语音合成服务，配置在广州区域
3. **OpenAI TTS**: 备选语音合成方案
4. **Edge TTS**: 本地TTS备选方案，无需API密钥

#### 视频处理
5. **FFmpeg**: 本地视频处理工具，用于视频合成和转码
6. **阿里云百炼**: 视频口型替换（VideoRetalk）服务

#### 基础设施
7. **PostgreSQL**: 关系型数据库，用于数据存储
8. **Redis**: 缓存和消息队列服务
9. **发布模式**: 当前为模拟发布（mock模式）

### 6.3 发布平台策略调整

#### 核心调整
- **发布优先级**: 从多平台调整为以抖音和小红书为主
- **平台选择理由**:
  1. 抖音: 短视频内容分发核心平台，用户基数大
  2. 小红书: 图文+短视频内容社区，适合深度内容

#### 抖音平台需求
- **视频格式**: MP4格式
- **时长限制**: 普通用户最长15分钟
- **分辨率要求**: 720P以上
- **文件大小**: 建议小于100MB
- **内容类型**: 短视频为主，支持多种内容形式

#### 小红书平台需求
- **内容形式**: 支持图文笔记和短视频
- **视频时长**: 笔记视频最长60秒
- **图片数量**: 最多9张图片
- **文字限制**: 最多1000字
- **标签系统**: 最多10个标签
