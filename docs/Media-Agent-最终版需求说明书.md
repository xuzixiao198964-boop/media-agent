## 1. 具体功能需求

### 1.1 用户认证管理功能
- **注册**: 仅用户名+密码，用户名3-64字符，密码12-128字符含4种类型
- **登录**: 仅用户名+密码，IP限制5次/5分钟，用户限制3次/10分钟
- **会话**: JWT访问令牌30分钟，刷新令牌7天，最多3个并发会话

### 1.2 资讯抓取功能
- **RSS格式**: RSS 2.0和Atom 1.0
- **抓取频率**: 7种预设(15分钟-24小时)
- **网页解析**: Readability算法，内容提取>90%，广告去除>95%
- **去重机制**: SHA-256哈希，95%相似度视为重复

### 1.3 视频处理功能
- **支持格式**: 8种(MP4, MOV, AVI, MKV, FLV, WMV, WebM, MPEG)
- **文件大小**: 单个最大2GB，用户存储免费2GB/付费10GB
- **分片上传**: 5MB/片，最多400片，支持断点续传
- **视频处理**: 格式转换(MP4 H.264/AAC)，分辨率调整(6种)，水印添加

### 1.4 AI内容生成功能
- **AI模型**: 仅DeepSeek系列
  1. DeepSeek-V3（主要使用）
  2. DeepSeek-R1（推理增强）
  3. DeepSeek-Coder（代码生成）
- **文案模板**: 12种预定义模板
- **TTS语音**: 3个提供商12种语音
- **视频模板**: 8种预定义模板
- **流水线管理**: 5种节点类型，3种预定义工作流

### 1.5 发布管理功能
- **支持平台**: 6个具体平台
  1. YouTube (视频，最大128GB，最高8K)
  2. TikTok (短视频，最大500MB，3分钟)
  3. Instagram (Reels/Feed/Story，最大4GB)
  4. Bilibili (视频，最大8GB，最高4K)
  5. 抖音 (短视频，最大500MB，15秒-5分钟)
  6. 微信视频号 (短视频，最大1GB，30秒-30分钟)

## 2. 性能需求

### 2.1 性能要求原则
- **根据服务器具体性能确定**: 所有性能指标根据实际服务器硬件配置动态调整
- **可配置性**: 所有性能参数在配置文件中可调整
- **弹性伸缩**: 系统支持根据负载自动调整资源分配

### 2.2 任务队列总等待时间要求
- **高优先级任务**: 等待时间不超过服务器处理能力的10%
- **普通优先级任务**: 等待时间不超过服务器处理能力的30%
- **低优先级任务**: 等待时间不超过服务器处理能力的50%

### 2.3 队列积压处理
- **轻度积压(<50个任务)**: 系统自动加速处理
- **中度积压(50-200个任务)**: 系统告警，建议增加资源
- **重度积压(>200个任务)**: 系统自动限流，拒绝新任务提交

## 4. 具体业务路径（12种）

### 4.1 资讯转视频（3种）
1. **自动资讯转视频**: RSS源→定时抓取→AI摘要→TTS语音→视频合成→自动发布
2. **手动资讯转视频**: 用户选择文章→配置参数→生成预览→确认生成→手动发布
3. **批量资讯转视频**: 文章列表→批量任务→后台处理→进度监控→批量导出

### 4.2 视频处理（3种）
1. **单视频上传处理**: 本地文件→分片上传→自动转码→编辑信息→保存到库
2. **批量视频处理**: 文件列表→批量上传→统一处理→进度监控→批量导出
3. **视频发布流程**: 选择视频→选择平台→配置参数→提交任务→监控状态

### 4.3 AI内容生成（3种）
1. **单次文案生成**: 输入内容→选择模板→配置参数→DeepSeek生成→编辑保存
2. **文案转语音视频**: 选择文案→语音合成→选择模板→视频合成→预览发布
3. **自定义工作流**: 创建工作流→配置节点→执行工作流→监控进度→查看结果

### 4.4 发布管理（3种）
1. **单视频多平台发布**: 选择视频→勾选平台→配置参数→提交任务→监控汇总
2. **批量视频发布**: 选择视频→批量任务→配置策略→提交任务→监控报告
3. **定时发布计划**: 创建计划→配置规则→保存计划→自动执行→监控历史
