# Media Agent 核心功能性能需求

## 文档定位
专注于功能需求、性能指标、多角度健壮性设计，去除运维、计划、测试等非核心内容。

## 一、核心功能需求

### 1.1 用户认证管理
#### 注册功能
- 仅用户名+密码，实时验证
- 密码：12字符，必须包含大写、小写、数字、特殊字符
- 用户名：3-64字符，字母数字下划线
- 健壮性：并发控制、重复检测、频率限制

#### 登录功能
- 登录限制：
  - IP级：5分钟内失败5次 → 封锁30分钟
  - 用户级：10分钟内失败3次 → 锁定15分钟
  - 渐进延迟：失败越多延迟越长（最大30秒）
- 会话管理：
  - JWT令牌：访问令牌30分钟，刷新令牌7天
  - 自动刷新：过期前5分钟自动刷新
  - 并发控制：默认3个并发会话
- 健壮性：令牌黑名单、会话持久化、跨设备同步

#### 密码管理
- 密码修改：需验证旧密码
- 历史检查：禁止使用最近5次密码
- 过期提醒：90天过期，提前7天提醒
- 健壮性：bcrypt哈希、历史密码加密、修改频率限制

### 1.2 资讯抓取
#### RSS源管理
- 支持RSS/Atom格式，自动验证
- 抓取频率：15分钟-24小时可配置
- 健壮性：源验证、失败重试、资源控制

#### 网页抓取
- 智能解析：自动识别主体内容
- 内容清洗：去除广告导航，格式规范化
- 图片处理：自动下载优化
- 去重机制：基于内容哈希
- 健壮性：解析容错、超时控制、资源回收

#### 内容管理
- 分页列表：多种排序方式
- 内容预览：富文本显示，简单编辑
- 批量操作：选择、删除、导出、标记
- 搜索过滤：标题、内容、来源、时间多维度
- 健壮性：高效分页、搜索优化、批量事务

### 1.3 视频处理
#### 视频上传
- 格式支持：MP4、MOV、AVI、MKV、FLV
- 大文件：分片上传，断点续传
- 批量上传：多文件并发，进度显示
- 健壮性：上传容错、格式验证、资源隔离

#### 视频预览
- 在线预览：无需下载，多分辨率
- 缩略图：自动生成，可自定义时间点
- 基本信息：时长、分辨率、码率、格式
- 时间轴：拖动预览，快速定位
- 健壮性：预览缓存、格式兼容、资源优化

#### 视频处理
- 格式转换：自动转MP4，编码可调
- 分辨率调整：多种预设，自动优化
- 水印添加：文字/图片，位置透明度可配
- 健壮性：处理队列、失败重试、资源监控

### 1.4 AI内容生成
#### AI文案生成
- 多模型：GPT-3.5/4、Claude、本地模型
- 模板系统：预定义模板，支持自定义
- 风格控制：正式、幽默、简洁、专业
- 长度控制：短、中、长文案
- 健壮性：模型降级、请求限流、结果缓存

#### TTS语音合成
- 多语音：多种语音库和语言
- 情感控制：高兴、严肃、激动、平静
- 语速调整：快慢可调，停顿重音可配
- 健壮性：合成队列、格式兼容、资源回收

#### 视频合成
- 模板系统：预定义模板，可编辑自定义
- 素材组合：自动组合文案、语音、图片/视频
- 字幕生成：自动同步字幕，多种样式
- 健壮性：合成容错、进度跟踪、资源管理

#### 流水线管理
- 工作流定义：可视化定义，条件分支
- 批量处理：并发控制，优先级设置
- 进度监控：实时进度、状态、预计时间
- 健壮性：工作流持久化、断点续做、资源隔离

### 1.5 发布管理
#### 平台管理
- 平台支持：TikTok、YouTube、Instagram、Facebook、Twitter
- 账号管理：多账号添加验证管理
- 平台配置：发布参数，API密钥
- 健壮性：平台降级、账号轮换、配置验证

#### 发布配置
- 内容适配：自动适配平台格式
- 发布计划：立即、定时、循环发布
- 发布策略：频率、时间窗口、重试策略
- 健壮性：配置验证、计划容错、策略降级

#### 发布执行
- 任务队列：优先级和并发控制
- 状态跟踪：实时状态，详细日志
- 失败重试：自动重试，智能策略
- 健壮性：队列持久化、状态一致性、重试智能

#### 发布监控
- 实时监控：任务状态、进度、性能指标
- 统计报表：成功率、平台分布、时间分布
- 异常告警：失败、超时、频率异常
- 健壮性：监控容错、数据聚合、告警去重

## 三、多角度健壮性

### 3.1 功能健壮性
#### 输入验证
- 边界条件：最小/最大值、空值处理
- 格式验证：数据格式、文件格式、编码
- 业务规则：状态验证、权限验证、依赖验证

#### 业务流程
- 操作原子性：数据库事务、分布式最终一致性、补偿机制
- 流程可恢复：断点续做、状态持久化、超时处理
- 异常处理：业务异常明确处理、系统异常优雅降级、级联异常隔离

#### 数据一致性
- 实时一致性：关键数据强一致性、读写一致性、缓存一致性
- 最终一致性：异步同步、冲突解决、定期检查
- 数据恢复：定期备份、备份验证、恢复测试

### 3.2 性能健壮性
#### 负载均衡
- 请求分发：智能负载算法、健康检查、故障转移
- 资源分配：动态扩缩容、资源预留、资源回收
- 性能隔离：用户隔离、功能隔离、优先级隔离

#### 容量规划
- 数据容量：存储预估、容量预警、自动清理
- 处理容量：并发控制、队列管理、批量处理
- 网络容量：带宽预估、流量控制、CDN优化

#### 性能降级
- 功能降级：非核心功能降级、简化流程、缓存优先
- 性能降级：保证核心响应时间、适当降低数据实时性
- 体验降级：界面简化、异步操作、进度提示

### 3.3 可用性健壮性
#### 服务可用性
- 服务冗余：多实例部署、跨可用区、自动故障转移
- 依赖健壮：依赖隔离、超时控制、智能重试
- 启动恢复：快速启动、状态恢复、健康检查

#### 数据可用性
- 数据冗余：主从复制、数据分片、异地备份
- 访问健壮：读写分离、连接池管理、查询优化
- 恢复健壮：多级备份、标准流程、定期测试

#### 网络可用性
- 网络冗余：多线路接入、DNS冗余、CDN加速
- 连接健壮：连接池、心跳检测、超时重试
- 安全防护：DDoS防护、流量清洗、访问控制

### 3.4 安全健壮性
#### 认证安全
- 密码安全：强密码策略、加盐哈希存储、HTTPS传输
- 会话安全：JWT签名验证、会话超时控制、防会话固定
- 登录安全：失败限制、异地登录检测、设备管理

#### 授权安全
- 权限模型：RBAC模型、权限实时验证、权限继承
- 数据权限：行级权限、列级权限、操作权限控制
- 审计日志：操作审计、权限变更记录、安全事件记录

#### 数据安全
- 传输安全：全程HTTPS加密、证书管理、安全协议
- 存储安全：敏感数据加密、访问控制、数据脱敏
- 销毁安全：安全删除、存储清理、备份管理

#### 应用安全
- 输入安全：SQL注入防护、XSS防护、CSRF防护
- 输出安全：安全响应头、错误信息保护、数据泄露防护
- 代码安全：代码审查、依赖漏洞监控、安全更新

## 五、健壮性设计原则

### 5.1 功能健壮性原则
- **防御性编程**: 假设所有输入都可能有问题
- **错误处理**: 所有可能的错误都有处理方案
- **数据保护**: 重要数据有多重保护机制

### 5.2 性能健壮性原则
- **容量规划**: 基于业务增长的容量规划
- **性能隔离**: 不同功能性能相互隔离
- **降级策略**: 高负载时优雅降级策略

### 5.3 可用性健壮性原则
- **冗余设计**: 关键组件冗余设计
- **故障隔离**: 单点故障不影响整体
- **快速恢复**: 故障快速检测和恢复

### 5.4 安全健壮性原则
- **最小权限**: 只授予必要的权限
- **纵深防御**: 多层安全防护
- **安全审计**: 所有安全事件都有记录
